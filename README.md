# Акции по эквайрингу и СБП

Дашборд по действующим предложениям шести банков (Сбер, Альфа, ГПБ, ВТБ,
Т-Банк, БСПБ). Обновление запускается вручную с ноутбука одной командой;
GitHub только раздаёт готовую страницу через Pages.

```bash
./update.sh
```

Собрать → извлечь → проверить → пересобрать HTML → запушить. Страница
обновляется через 1–2 минуты после пуша.

## Как это устроено

```
fetch.py  →  extract.py  →  validate.py  →  build.py  →  git push  →  Pages
Playwright    Gemini         приёмка        Jinja2
```

| Файл | Что делает |
|---|---|
| `update.sh` | Прогоняет весь цикл и публикует |
| `src/fetch.py` | Открывает 6 страниц в headless-браузере, кладёт текст в `data/snapshots/<дата>/` |
| `src/extract.py` | Отдаёт текст Gemini со строгой JSON-схемой, получает структурированные условия |
| `src/validate.py` | Отбраковывает мусор и накладывает проверенное на `data/banks.json` |
| `src/build.py` | Собирает `docs/index.html` из данных и шаблона |
| `src/schema.py` | Модель данных — общая для всех четырёх шагов |

`data/banks.json` — единственный источник правды. HTML руками не правится:
любая правка содержания идёт в JSON, дальше `build.py`.

**Почему браузер, а не `requests`.** Пять сайтов из шести отдают обычный
SSR-HTML, но у Альфа-Банка стоит JS-челлендж ServicePipe — без браузера
приходит полтора килобайта со спиннером.

**Почему LLM, а не CSS-селекторы.** Банки перекраивают лендинги несколько
раз в год. Селектор ломается молча: отдаёт пустоту или чужое число. Модель
со схемой переживает редизайн, а от её фантазий защищает `validate.py`.

## Установка (один раз)

```bash
pip install -r requirements.txt
python -m playwright install chromium
cp .env.example .env          # и вписать ключ из https://aistudio.google.com/apikey
```

`.env` в `.gitignore` — ключ остаётся на ноутбуке и на GitHub не уезжает.

## Режимы запуска

```bash
./update.sh              # полный цикл с публикацией
./update.sh --local      # всё собрать, но не пушить — посмотреть перед публикацией
./update.sh --rebuild    # только пересобрать HTML из данных: без сети, без ключа
```

`--rebuild` нужен после правки шаблона или текста в `data/banks.json`:
ходить на сайты банков ради этого незачем.

Отдельные шаги, если нужно разобраться:

```bash
python src/fetch.py --bank alfa                  # один банк
python src/extract.py --dry-run                  # извлечь и показать, ничего не записывая
python src/validate.py --check-only              # отчёт приёмки, banks.json не трогать
python src/extract.py --snapshots data/snapshots/2026-07-21   # прогнать по старому снимку
```

## Лимиты Gemini

Бесплатный тир даёт **20 запросов в сутки** на модель (`gemini-3.5-flash`).
Один прогон — ровно 6 запросов, по одному на банк, так что суточного лимита
хватает на три полных обновления.

Выжечь его легко, если запускать `src/extract.py` подряд при отладке: каждый
повтор считается отдельным запросом. Признак — ошибка `RESOURCE_EXHAUSTED`
с `quotaId: GenerateRequestsPerDayPerProjectPerModel-FreeTier`. Сброс в
полночь по тихоокеанскому времени, около 10–11 утра по Москве.

Проверить остаток и работоспособность ключа одним запросом:

```bash
curl -s "https://generativelanguage.googleapis.com/v1beta/models?key=$GEMINI_API_KEY" | head -5
```

Модели заданы списком в [`src/extract.py`](src/extract.py): основная
`gemini-3.5-flash`, запасная `gemini-3.1-flash-lite` на случай ответа 503
«high demand». Запасная заметно слабее — теряет часть ставок, — поэтому
после прогона на ней стоит сверить результат глазами.
Версии зафиксированы намеренно: `gemini-flash-latest` молча переезжает
на новое поколение, и извлечение менялось бы без единой правки в коде.

## Что защищает от мусора

Публикация идёт без ревью, поэтому между галлюцинацией модели и живой
страницей стоит `validate.py`:

- ставка вне 0–5%, дата дальше двух лет, акция без названия — значение выбрасывается;
- цитата, которой нет в снимке страницы, — признак выдумки, значение выбрасывается;
- банк без единого пригодного значения сохраняет прошлые данные и получает
  статус `stale` — на карточке появляется «данные от такого-то числа»;
- **если развалилось больше двух банков из шести, `update.sh` останавливается
  и ничего не публикует.**

Сырые снимки страниц лежат в `data/snapshots/<дата>/` (в репозиторий не
коммитятся) — по ним видно, что реально было на странице банка.

## Публикация на GitHub

Pages настроен на ветку: **Settings → Pages → Source: Deploy from a branch →
Branch: `main`, папка `/docs`**. Никаких GitHub Actions и секретов на GitHub
не нужно — пуш `docs/index.html` сам обновляет сайт.

## Добавить седьмой банк

Одна запись в `data/banks.json` — достаточно `id`, `name`, `color`,
`source_url`, `checked_at`, `status: "seed"`; остальное заполнит первый же
прогон. Ни шаблон, ни скрипты трогать не нужно.

## Оговорка

Данные собираются автоматически с публичных страниц банков и могут содержать
неточности. Страница не является публичной офертой; условия уточняйте в банке.
